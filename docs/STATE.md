# `tc` — State Index

> Thin index — read first in a new session. Machine-of-record for task state is `tsk`. Deep history in `docs/state/*`.

**Phase:** Desktop client (Tauri + Solid) — feature-complete core, polishing OS-integration. Latest release **1.12.2**, protocol **3**.

## Recently closed (newest first)

- The window you couldn't get back (`z9wczl`, **v1.12.2**, desktop): closing the window on macOS left a running app showing nothing and unrecallable. Measured on the installed build — process alive, 0 windows, `open -a` inert. With `close_to_tray = true` the window was *hidden*, correctly; what was missing is that `.run()` had no `RunEvent` handler, so `RunEvent::Reopen` (Dock click) was ignored and only the tray could bring it back. Behind it, the default `false` path destroyed the window while the process lived on, after which even the tray's "Show window" no-ops (it resolves by label). Now: `CloseRequested` always `prevent_close` then hide-or-exit, so the main window is never destroyed while the app lives; `Reopen` handled on macOS; `close_to_tray` moved to `Arc<AtomicBool>` + a `CloseToTray` state because the main-thread handler cannot await the core mutex. Default is now **hide on macOS**, quit elsewhere. All three branches verified against a dev build. See `closed-desktop.md` → "The window you couldn't get back".

- Room-shell fixes (`5x7lo4`, `cygn5s`, **v1.12.1**, frontend only): falling speech no longer cut short — a new line from the same voice used to remove the previous one, so a second message wiped the first out of the air; lines now stack and each finishes its fall, a newcomer starting below the previous one when their boxes overlap (geometry, not age — in a crowded room a line covers its start point for seconds). And settings values stopped landing on their own action words: `.fixed` in `styles.css` collided with **Tailwind's `.fixed` utility**, both rules applied, `position: fixed` took the value out of flow; renamed `.value`. Diagnosed by rebuilding the row against the built stylesheet in a browser. See `closed-desktop.md` → "Falling text lives out its fall" and `decisions.md` → "A hand-written class shares a namespace with every Tailwind utility".

- Onset click (`kfx6og`, **v1.12.0**, client-only): every phrase started with a click, and the cause was a chain of compensations — the RMS gate clips onsets → `VadPreroll` compensates → its flush sends `VAD_PREROLL_FRAMES + 1` packets as one burst → the receive path decodes them immediately (the jitter buffer delays nothing) → `playback_buf` overshoots `MAX_PLAYBACK_BUF` on **every** talkspurt → the latency trim spliced the waveform mid-swing. `PlaybackQueue` (`client/audio.rs`) now owns every edit to the playback timeline and ramps both over `PLAYBACK_FADE_MS`: crossfade across the trim, fade at the silence↔data boundary (phrase endings improved too). Latency cap left at 100 ms by choice. Codec state ruled out — encoder and decoder freeze on the same frame and resume consistently. Follow-ups `4rg56x` (comfort noise) and `ta0vu0` (continuous DTX timeline, the NetEq-style structural fix). Same release drops prebuilt terminal-client binaries: releases carry the desktop app and the server, `install.ps1` removed, `install.sh` installs the server. See `closed-cli-core.md` → "Playback timeline" and `decisions.md` → "Voice quality".

- Voice trace (`n4vpum`, unreleased, desktop UI only): speaking hangs a thin string under a name and sends a wave down it, away from the mouth; three seconds of silence and the string is gone — the visual sibling of speech falling as text, in the same column, below the words in paint order. The sine is the carrier, the voice is the amplitude: levels arrive at 5 Hz from `level_pump.rs`, so an oscilloscope would be invented data. Phase is bound to the sample index, not the clock, so a burst leaves as one travelling crest instead of wobbling in place. Fed from `Cast`'s existing rAF loop (no second source of truth about loudness); 24-sample ring → one normalised SVG path (`lib/trace.ts`, `non-scaling-stroke`), fade by static CSS mask, a path per audible peer per frame and exactly zero once the string settles. Crowd (>8 standing) and reduced-motion follow the rules the falling text already set. No Rust, no dependency, no wire change. See `closed-desktop.md` → "Voice trace" and `decisions.md` → "A string hangs from every name".

- Desktop «Room» UI — full frontend replacement (`fhq8x7`, unreleased): the Discord-clone shell (sidebar + pane + peer panel) is gone. One layout serves every screen — **a row of entities, details underneath, a line to type into** — with people (room), rooms (lobby) or setting groups (settings) standing in that row. People *are* their names: volume is `scale`+opacity, ranks alternate counts so rows never form a grid, past 14 standing only recent voices stay and the quiet wait in a line below. Speech falls from the speaker and fades. All 28 settings speak the same grammar (one control: a row of words, lit = chosen; hotkeys are caught, not typed) with search across groups. Command output is routed — text-only commands open the history, `/list` opens the lobby, everything else echoes above the input line. Removed 9 components, added `components/room/*` + `lib/{scene,stage,tint,rooms}.ts`; `Palette`/`InviteConfirm`/`DevicePrompt`/`UpdateNotification`/`Identicon` kept. **No Rust changed** (ADR-0001 held). See `closed-desktop.md` → "«Room» UI" and `decisions.md` → "Desktop «Room» UI".

- Windows autostart fix + version surfacing (**v1.9.19**): autostart toggle threw `os error 2` on Windows — bundled `auto-launch` 0.5 *opens* `HKCU\…\Run` instead of creating it; Windows now writes the Run value directly via `winreg` (`create_subkey` idempotent, delete tolerates absent, quoted exe path), plugin kept for mac/linux. Client version shown at the bottom of desktop Settings + `/version` in both clients. See `decisions.md` → "Windows autostart".
- Voice quality + privacy pack (**v1.9.18**, both clients): **noise suppression** (RNNoise via `nnnoiseless`, opt-in, pre-encode in capture thread, `/denoise` + desktop toggle); **HD-voice** Opus ceiling 32→64 kbit/s (fullband emerges at that rate) + `signal=Voice`, tiers rebalanced; **paranoid mode** — traffic-analysis resistance (constant packet rate + flat CBR/DTX-off size, comfort silence on mute) so the relay can't infer who's speaking when (`/paranoid` + desktop toggle). All three: live-toggle `Arc<AtomicBool>` on the capture thread, persisted, zero wire/server change, hot-path allocation-free. See `decisions.md` → "Voice quality" / "Paranoid mode". New dep: `nnnoiseless` (pure Rust).
- Sound check / echo test (`x6hyqs`, **v1.9.17**, shared+server+both clients): 5 s live echo through the server — mic → Opus → XChaCha20 → UDP → server reflects → decode → playback, so you hear yourself back. Tests mic, headphones, codec, crypto, jitter **and** the round-trip in one action. Desktop button in Settings → Audio (countdown + verdict) and `/echotest` in both clients. Server stays a dumb relay: ephemeral single-member `echo-<id>` channel, reflects ciphertext to the tester's *registered* address (no reflection vector), never decrypts/stores. New additive wire msgs `StartEchoTest`/`StopEchoTest`/`EchoTestReady`; `PROTOCOL_VERSION` unchanged. e2e test proves byte-identical reflection to the sender. See `decisions.md` → "Sound check / echo test".
- Phantom-wave root cause + voice UX (`c8y7zv`, **v1.9.16**): Solid `setState` merge (keys never deleted) was THE phantom-wave cause — speaker levels now go through `reconcile()`; VAD pre-roll (100 ms ring) fixes clipped/scratchy speech onsets; server broadcasts `ChannelList` to all clients when a public channel is created; default VAD level 15 in both clients.
- Device UX & stability pack (`kihuol`, **v1.9.15**, client+UI): capture/playback split into independent halves behind swappable ring-buffer slots (no mic = listen-only, no output = speak-only, neither = chat works, audio self-heals); calls follow the system default device; settings device changes apply mid-call; hot-plug "use it now?" toast (configured device reconnecting switches back silently); `no mic`/`no audio out` chips in VoiceStrip.
- Audio device lifecycle resilience (`hqvzm9`, **v1.9.14**): macOS bundle was missing `NSMicrophoneUsageDescription` — the installed app silently got mic zeros and never prompted (dev worked via the terminal's TCC grant); added `src-tauri/Info.plist` + `Entitlements.plist`. Stream-death detection (error callbacks + capture starvation watchdog) → `VoiceHandle::is_healthy()`; the desktop voice actor supervises and rebuilds the pipeline (throttled, retries failed starts); stale device names fall back to the system default instead of failing the join.
- Jitter forward-gap resync (`3b6rh2`, **v1.9.13**, client-only): a loss burst longer than the ring (15 pkts = 300 ms, e.g. the deaf window while registration re-heals) wedged the jitter buffer forever — audio silent, speaking indicator alive. Resync after `JITTER_RESYNC_AFTER` consecutive out-of-window packets; single strays can't reset a healthy stream.
- Self-healing UDP registration (`80wpaa`, **v1.9.12**, server + client): idle keepalive now re-hellos with the real token (token-0 kept NAT mappings alive but not the relay registration — a NAT rebind left the client permanently deaf, proven via nettop on the live app socket vs a fresh probe listener on the same NAT); server cleanup no longer expires tokens of live in-channel sessions.
- Phantom speaking indicator fix (`u6l9cm`, **v1.9.11**): `level_pump` now emits `voice_stopped` on the active→inactive flip, `left_channel` clears voice state, a 1s frontend watchdog zeroes meters if `voice_level` stalls; `input_peak` resets to 0 on mute; the settings test tone hard-stops inside the audio callback (no endless beep on a wedged stream teardown). Proven by a probe listener: the channel carried zero packets while the UI showed a "constant stream" — the waves were a frozen frontend snapshot, not network traffic.
- Concurrent-speakers fix (`oyvhmx`, **v1.9.10**): per-sender jitter buffer + Opus decoder (`HashMap<name, SenderStream>` in `client/voice.rs`) with PCM mixing into playback; the old shared buffer reset on every interleaved packet → two people speaking at once = silence for everyone. Plus an echo guard: inbound packets carrying our own name are dropped (a loopback through a peer no longer plays your voice back to you).
- tc:// invite pack (`nmhah9`…`go7i87`): single-instance forwarding (Win/Linux), буферизация invite при холодном старте (`deeplink::Gate` + `take_pending_invite`), `register_all()` для dev/AppImage, `/invite` в обоих клиентах (`tc_shared::invite_url`), join без setTimeout, confirm-диалог для серверов вне registry (анти drive-by).
- Кросс-платформенные тесты (`fxwmpb`): CI-матрица [ubuntu/macos/windows] для `cargo test`, dual-stack e2e по `::1`, behavioral `BatchSender` (реально исполняет sendmmsg/sendmsg_x/fallback). Матрица сразу поймала 2 реальных падения (macOS CMake, Windows UDP-readiness). Релиз **v1.9.8**.
